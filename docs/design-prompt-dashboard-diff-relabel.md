# Claude Designへの追加指示プロンプト: 判断待ち→レビュー待ちへの変更ボタン（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #274）。既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けて使います。単独では使わない。

---

## ここからプロンプト

判断待ち（needs-human-decision）カードに「レビュー待ちに変更」ボタンを追加してください。目的: AIの遷移漏れで本来レビュー待ちのissueが判断待ちになっている場合に、人間がUIからレビュー待ち(status:in-review)へ直せるようにします。

仕様:
1. 判断待ちカードの既存の承認・差し戻し等の操作群の近くに、控えめなセカンダリボタン（既存ボタンと同じ寸法・角丸・フォントで、承認ボタンより目立たない見た目）として配置。ラベルは「レビュー待ちに変更」。
2. 誤操作防止のため、クリックで確認ダイアログ（既存の確認ダイアログのスタイルを踏襲）を表示。文言例「このissueをレビュー待ちに変更します。AIへの指示コメントは投稿されず、ラベルのみ変更されます。」ボタンは「変更する」「キャンセル」。
3. 実行中はボタンを無効化しスピナー表示、成功後はカードが判断待ち一覧から消えレビュー待ち側へ移る。失敗時は既存のエラー表示を踏襲。
4. 読み取り専用モード時は既存の書き込み系ボタンと同様に失敗表示になる。
5. ダーク／ライト両テーマ、デスクトップ／モバイル両対応。
