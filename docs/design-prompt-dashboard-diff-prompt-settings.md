## ここからプロンプト

既存のproducer-deskダッシュボードのデザインに、**Agent Runnerプロンプト設定画面**を追加してください。既存の画面（ダッシュボード／プロジェクト別issue一覧／プロジェクト設定ダイアログ）のデザイン・配色・コンポーネントのトーンはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html`）は直接上書きせず、`feature/issue-149-prompt-settings.dc.html` という新規ファイルとしてデザインを作成してください。**

### 背景

Agent Runner（AIエージェント）を起動するたびに、システムプロンプトとして複数の指示文が渡されています（状態ラベル遷移の指示、コメントマーカー付与の指示など、全4種類）。これをダッシュボードから閲覧・編集できるようにします。誤編集でシステムが壊れないよう、**必須トークン**（プロンプト中に必ず残さなければならない文字列）の説明表示と、デフォルト値へのリセット手段が必要です。

### 追加する画面: プロンプト設定ページ

- サイドバーに「プロンプト設定」ナビゲーション項目を追加する（既存の「ダッシュボード」「issue一覧」と同列。モバイルのボトムナビにも相当する導線を用意）。
- ページ構成は**一覧＋編集**。PC幅では左にプロンプト一覧、右に選択中プロンプトの編集エリア（2ペイン）。モバイル幅では一覧→タップで編集画面に遷移する形にする。
- ページ上部に常時、次の注記を表示する: 「変更は次回以降のAgent Runner起動分から反映されます。実行中のセッションには反映されません。」

#### 一覧の各行に表示するもの

- プロンプト名（日本語の表示名）と、内部キー（等幅フォント、例: `label_instruction`）
- 状態バッジ: 「デフォルト」／「編集済み」
- 必須トークンを持つプロンプトには、盾や鍵のような小さなアイコンで「必須トークンあり」を示す

対象のプロンプトは次の4種類（実データのサンプルとして使ってください）:

1. 状態ラベル遷移の指示（`label_instruction`）— 必須トークンあり
2. コメントマーカー付与の指示（`comment_marker_instruction`）— 必須トークンあり
3. PR作成時の指示（`pr_instruction`）
4. 最終応答の書き方の指示（`final_message_instruction`）

#### 編集エリア

- 大きめの等幅フォントのテキストエリア（複数行・リサイズ可能）
- テキストエリアの上に、**必須トークンの説明パネル**（最重要）。内容は次の通り:
  - 見出し: 「必須トークン」と、削除すると何が壊れるかの警告アイコン付き説明文
  - トークンを1つずつチップ（等幅フォント）で一覧表示し、各チップに「なぜ必要か」を添える。例（`comment_marker_instruction`の場合）: `<!-- producer-desk:bot-comment -->` — 「このマーカーが無いと、AI自身のコメントが人間の新規指示と誤認され、同一内容が無限に再ディスパッチされます」
  - 例（`label_instruction`の場合）: `status:in-review` / `needs-human-decision` — 状態遷移に必要なラベル名、`<!-- producer-desk:ci-wait` — CI完了待ち再開のための機械可読マーカー
  - 必須トークンを持たないプロンプトでは、このパネルの代わりに「このプロンプトに必須トークンはありません」と控えめに表示する
- **利用可能なプレースホルダ**の説明（`{repo}` / `{issue_number}`がAgent Runner起動時にそれぞれリポジトリ名・issue番号に置換される旨）。クリックでカーソル位置に挿入できるチップにする。それ以外の `{xxx}` は使えない旨も明記する。
- **リアルタイム検証表示**: テキストエリアの内容に必須トークンが欠けている場合、該当トークンのチップを警告色（既存の警告・エラー表現に合わせる）に変え、「保存できません: 〇〇が含まれていません」というインラインエラーを表示し、保存ボタンを無効化する。未知のプレースホルダ（例: `{foo}`）を含む場合も同様。すべて満たしている場合は、チップが成功色（チェックマーク付き）になる。
- ボタン: 「保存」（主ボタン）、「デフォルトに戻す」（副ボタン。押すと確認ダイアログを経てコード内蔵の初期値へ戻す）、「変更を破棄」。
- デフォルトから変更がある場合は、保存前に「デフォルトとの差分を見る」トグルで簡易的な差分表示（追加行/削除行の色分け）ができると望ましい。
- 保存成功時は既存のトースト通知で「保存しました。次回のAgent Runner起動から反映されます」と表示する。

### 成果物として欲しいもの

1. PC幅の2ペイン画面（必須トークン説明パネル付きの編集状態）
2. モバイル幅での一覧画面と編集画面
3. 検証エラー状態（必須トークン欠落時）と正常状態の見え方の対比
4. 「デフォルトに戻す」の確認ダイアログ
5. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。不明点があれば、作成を進める前に質問してください。
