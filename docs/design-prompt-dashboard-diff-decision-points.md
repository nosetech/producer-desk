# Claude Designへの追加指示プロンプト: 返信UIの引用領域に「判断が必要な事項」を列挙する（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #234。[design-prompt-dashboard-diff-comment-viewer.md](./design-prompt-dashboard-diff-comment-viewer.md)の返信UI内コメント表示の後に依頼する想定）。既に作成済みのモックアップ（Artifact）がある場合は、それを更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインのうち、**返信入力欄の上に表示している「返信先コメントの引用領域」**を変更してください。既存のレイアウト・配色・コンポーネント構成（引用領域のヘッダー：AIタグ・投稿者・時刻・前後コメント切替・GitHubで開く・折りたたみ）はそのまま維持し、引用領域の本文部分だけを変更します。

### 背景

AIの最終応答は、作業報告・変更内容・PR情報・「人間に判断してほしい点」が一続きに書かれることが多く、プロデューサーが本当に答えるべき判断事項が長文に埋もれます。返信を書くときは判断事項だけを見たいので、引用領域では判断事項を主表示にします。

### 変更内容

- 返信先コメントに**判断事項（「判断が必要な事項」セクション）がある場合**、引用領域の本文を次の表示にする。
  - 小見出し「判断が必要な事項」と件数。
  - 判断事項を**番号付きカード（またはリスト）で1項目ずつ**表示する。番号は目立たせ、本文は読みやすい文字サイズにする。
  - 項目に**選択肢**（A案／B案など）がある場合は、項目の下にインデントしたチップまたは箇条書きで、判断事項本文と見分けられるように表示する。
  - 末尾に「全文を見る」ボタン。押すと従来どおりのコメント全文表示（添付画像・動画を含む）に切り替わり、全文表示の側に「判断事項に戻る」操作を用意する。
- 返信先コメントに判断事項が**無い**場合、および返信先が issue 本文の場合は、現在の引用表示（折りたたみ時は1行要約、展開時は全文）のままにする。判断事項の枠は出さない。
- 判断事項の表示は、判断待ち・レビュー待ちを示す既存のアクセント色の言語に揃える（新しい色を増やさない）。

### 共通の要件

- 引用領域は最大高さを設けて内部スクロールとし、判断事項が多くても**返信textareaと送信ボタンが画面外に押し出されない**こと。
- モバイル幅（〜640px）でも成立すること（カードの余白を詰め、タップ領域は36px以上）。
- ダーク／ライト両テーマで配色を用意する。

### 更新後の成果物として欲しいもの

1. 既存のダッシュボードデザインに上記を統合した更新版（HTML/CSSのArtifact）
2. モバイル幅・PC幅それぞれでの見え方
3. 次の3状態の見本: 判断事項あり（選択肢あり／なしの項目が混在）、「全文を見る」で全文表示にした状態、判断事項なしのフォールバック表示

## 補足（プロンプトの外）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない。
- 判断事項の書式（見出し文言・番号付きリスト・選択肢）は [basic-design.md](./basic-design.md) 3-6の「判断事項セクションの書式仕様」で定義する。
- Claude Design側でデザインが更新されたら、実装時に`DesignSync`で実ソース（`ProducerDesk.dc.html`・`ProducerDesk.logic.js`）を取得し、`truncated`を確認したうえでスタイル値を読み取ってから実装すること（[CLAUDE.md](../CLAUDE.md)の「画面デザインの実装ルール」参照）。
