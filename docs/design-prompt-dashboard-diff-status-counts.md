# Claude Designへの追加指示プロンプト: プロジェクト状況ウィジェットの拡張・活動タイムライン廃止（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（[design-prompt-dashboard-diff.md](./design-prompt-dashboard-diff.md)の指示入力欄追加の後に依頼する想定）。既に作成済みのモックアップ（Artifact）がある場合は、それを更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインについて、既存の4要素のうち**「プロジェクトの並行状況が分かる要素」を拡張し、「最近の活動ログ（タイムライン）」を廃止する**形で更新してください。「判断待ち一覧」「利用量・リミットモニター」「新しい指示を出す入力欄」の3要素のデザイン・レイアウトはそのまま維持してください。

### 変更1: 「プロジェクトの並行状況」に状態別件数を追加する

現在このセクションは、プロジェクトごとのステータスチップ（今どの状態かを示すバッジ）を横並びに表示しています。これに加えて、**全プロジェクト横断の状態別件数**を表示してください。

- 表示する件数は5種類: 未着手／作業中／判断待ち／レビュー待ち／**タグなし**
- 「完了」件数は表示しません
- 「タグなし」は、本来付くはずの状態ラベルが何らかの理由で付いていないissueの件数です。**プロデューサーに「ラベル付け漏れ」というオペレーション上の異常に気づかせるための表示**なので、他の4状態（正常な進行状態）とは視覚的に区別してほしい（例: グレーではなく注意を引く色にする、0件のときは目立たせず1件以上のときだけ強調する、等）。ただし常時表示される警告のように過度に威圧的にならないよう配慮してください
- **既存のプロジェクトごとのステータスチップ表示は、この件数表示と統合してください**（両方を別々に並べるのではなく、1つのウィジェットとして一体化したデザインにする）。統合の具体的な表現（件数を上部サマリーとして置き、下にプロジェクト別チップを並べる／件数をクリックすると該当プロジェクトのチップにフィルタされる、等）はお任せします
- 色は`dataviz`スキルの状態別配色の方針、および前回デザインで使った状態バッジの配色（未着手/作業中/判断待ち/レビュー待ち/完了）との整合を保ってください

### 変更2: セクション全体を「枠で囲ったウィジェット」の見た目にする

現在「プロジェクトの並行状況」セクションだけが背景・枠線のない素の並びになっており、「利用量・リミットモニター」セクション（背景パネル＋枠線＋角丸で1つのカードとして囲われている）と比べて視覚的な一貫性がありません。他のセクションと揃うよう、セクション全体を1枚のパネル（カード）として枠で囲ってください。

### 変更3: 孤立した「作業中」issueの異常インジケータをチップに追加する

プロジェクトごとのステータスチップに、「作業中のはずなのに実際には処理が止まっている」という異常を示す最小限のインジケータ（警告アイコン等）を追加してください。詳細情報（どのissueが該当するか等）はこのチップには表示せず、チップをクリックした先の別画面（本デザインの対象外）で確認する想定です。チップ上では「何か異常がある」ことだけが一目で分かれば十分です。

### 変更4: プロジェクトごとのチップをクリック可能にする

各プロジェクトのチップ（またはチップ内の該当箇所）をクリック/タップ可能にし、そのプロジェクトの詳細画面（本デザインの対象外、別途実装）へ遷移できることが分かるホバー状態・カーソル表現を加えてください。遷移先自体のデザインは不要です。

### 変更5: 「最近の活動ログ（タイムライン）」を廃止する

複数プロジェクト横断の活動タイムライン要素は廃止してください。このセクションが占めていたレイアウト領域（現状のPC幅2カラムレイアウトで、右カラムに「利用量・リミットモニター」と並んでいた場合はそのカラム構成）をどう調整するか、提案してください（例: 右カラムを「利用量・リミットモニター」のみにして幅を広げる、1カラムに統合する、等）。モバイル幅でのレイアウト調整案も併せてお願いします。

### 更新後の成果物として欲しいもの

1. 既存のダッシュボードデザインに、上記の変更を反映した更新版（HTML/CSSのArtifact）
2. 「プロジェクトの並行状況」ウィジェットの状態別件数＋プロジェクト別チップ統合表示（タグなし件数の強調表現を含む）
3. 孤立した「作業中」インジケータ、チップのクリック可能な見た目（ホバー状態を含む）
4. 活動タイムライン廃止後のレイアウト調整案（PC幅・モバイル幅それぞれ）
5. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色の一貫性を保ってください。不明点があれば、更新を進める前に質問してください。

## 補足（プロンプト利用者向けメモ）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない（最初のダッシュボードデザインが未作成の場合は、まず元のプロンプトを使うこと）。[design-prompt-dashboard-diff.md](./design-prompt-dashboard-diff.md)（指示入力欄の追加）と合わせて適用する想定だが、順序に強い依存はない。
- 対応する仕様変更は [issue #115](https://github.com/nosetech/producer-desk/issues/115) を参照。状態別件数（`status_counts`、タグなし含む）はオーケストレータ側（`orchestrator/orchestrator/aggregation.py`の`aggregate()`）で実装済み。「タグなし」件数を表示する意図はラベル付け漏れの検知用途であることをプロデューサーに確認済み。既存のプロジェクト別ステータスチップ表示は件数表示に統合してよいことも確認済み（本プロンプトの「変更1」に反映済み）
- 孤立した「作業中」異常インジケータの詳細確認・チップのクリック遷移先は、本issueから切り出した [issue #116](https://github.com/nosetech/producer-desk/issues/116) で別途実装する
- デザイン更新後のArtifact URL/コードは、このリポジトリの実装issue（#115）に添付し、`CLAUDE.md`「画面デザインの実装ルール」のURLも更新すること
