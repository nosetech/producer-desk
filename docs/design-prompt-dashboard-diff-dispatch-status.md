# Claude Designへの追加指示プロンプト: 指示の処理状態チェック・再実行UI（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #215）。既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けて使います。単独では使わない。

---

## ここからプロンプト

各issueカード（判断待ち／レビュー待ち／プロジェクト別issue一覧の行）に、「状態をチェック」して必要なら「再実行」できるUIを追加してください。背景: 指示を出したのに、オーケストレータ停止や取りこぼし等で処理が実行されないことがあり、issueに指示を書き直す手間が大きいため。既存のレイアウト・配色・トーンは維持してください。

【要件】
1. 各issueに「状態をチェック」操作（控えめなボタン/メニュー項目）を追加する。
2. 押すと診断結果をカード内（インライン展開またはポップオーバー）に表示する。状態は次の6種: 実行中 / 実行待ち / 完了 / 未処理の指示あり / in-progressだが実行されていない（孤立） / 管理対象外。各状態に合う色・アイコンと短い説明文を付ける。
3. 再実行可能な場合（未処理の指示あり・孤立でコメントあり）のみ、「再実行」ボタンを出す。押す前に、再実行される指示コメントの文面を表示して確認させる（指示ではないコメントが対象になりうるため）。「未処理の指示コメントがありません」の場合はボタンを出さずその旨を表示する。
4. 再実行中・完了・失敗（「再試行」付き）の見せ方は、既存の「カード単位の非同期進捗表示」と同じ体験に揃える。別プロジェクトの操作をブロックしない。実行中・待機中は「すでに実行中のため再実行できません」と伝える（409相当）。
5. ライト/ダーク両方、モバイル幅・PC幅の見え方を示す。

不明点があれば、進める前に質問してください。
