# Claudeチャットへの追加指示プロンプト: レビュー待ちカードへのCI・レビュー結果・判断事項の表示（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #324）。[判断待ちカードへの判断事項の表示（issue #325）](./design-prompt-dashboard-diff-decision-card.md)の内容を引き継いだ差分です。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaudeとのやり取りに貼り付けてください。

## ここからプロンプト

既存のproducer-deskダッシュボードの**レビュー待ち（status:in-review）カード**を変更してください。カード以外の要素のデザイン・レイアウトはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-324-review-card.dc.html`（と対の`feature/issue-324-review-card.logic.js`）という新規ファイルとして作成してください。** マスターの`.logic.js`は256KiBに近いため、`.logic.js`はマスターのロジック一式（`ProducerDesk.inboxkeys.logic.js`まで）を読み込んで継承し、差分のスタイルだけを定義する形にしてください（過去の`feature/issue-339-inbox-shortcuts.logic.js`と同じ方式）。

### 背景

- レビュー待ちカードの要約は最新コメントを1行にまとめて3行で切っているため、AIの長い最終応答では判断に必要な部分が切れてしまい、毎回「全文を表示」を開いています。
- レビュー待ちカードで知りたいのは主に「CIが通っているか」「コードレビューの指摘にどこまで対応したか」「プロデューサーが判断すべき事項があるか」の3つです。
- AIの最終応答に、次の固定書式の「作業結果」セクションを出力させるようにします。判断事項は、判断待ちカードと同じ「判断が必要な事項」セクション（番号付きリスト＋選択肢）を併記することがあります。
  ```
  **作業結果**
  - CI: 完了        （または「未設定」）
  - レビュー: 指摘3件（対応済2件・未対応1件）   （または「未実施」）
  ```

### 変更内容

1. **カード上に作業結果を表示する**（最新コメントに「作業結果」セクションがある場合）
   - CI: `完了` / `未設定` を表示（失敗・実行中は想定しない）
   - レビュー: `未実施` / `指摘X件 対応済X件 未対応X件` を表示
   - **未対応が1件以上ある場合は目立たせる**（承認前に全文で理由を確認すべきため）。未対応0件の場合は落ち着いた表示に
   - 読み取れなかった項目（どちらか片方だけ書式が崩れている等）は、その行だけ非表示にする
   - ラベル・値・アイコン（ステータスを示す小さなアイコンやドット等）をどう並べるか、カード内でコンパクトに収まるレイアウトを決めてください
2. **カード上に判断事項を表示する**（最新コメントに「判断が必要な事項」セクションがある場合）
   - 判断待ちカード（issue #325）の判断事項ブロック（`decBox`〜「ほか N件を全文で確認」）と同じ見た目・省略ルールを踏襲する
   - 作業結果と判断事項が両方ある場合の並び順・間隔を決めてください
3. **フォールバック**: 作業結果も判断事項も無い（過去の応答・人間のコメント・書式に従っていない応答）場合は、従来どおり「AI」タグ付きの3行要約（添付件数表示を含む）を表示する。コメント0件のカードは従来どおり要約なし
4. 「承認」「返信」「全文を表示」ボタン、PRバッジ、ジョブ進捗表示、ディスパッチ診断、全文表示ダイアログは変更しない
5. **配色**: 既存の配色（レビュー待ちのアクセント色、成功・警告系の既存色）を使い、新しい色は増やさない

### 成果物として欲しいもの

1. レビュー待ちカードの次の状態の見本
   - CI完了・レビュー指摘すべて対応済
   - 未対応あり
   - CI未設定・レビュー未実施
   - 作業結果＋判断事項あり
   - パース不可（従来の要約へのフォールバック）
   - 実行中（マージの進捗表示あり）
2. PC幅・モバイル幅（〜640px、タップ領域36px以上）での見え方
3. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。不明点があれば、作成を進める前に質問してください。
