# Claude Designへの追加指示プロンプト: 指示入力欄の追加（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です。既に作成済みのモックアップ（Artifact）がある場合は、それを更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインに、**新しい指示を出す入力欄**を追加してください。既存の4要素（判断待ち一覧／最近の活動ログ／利用量・リミットモニター／プロジェクトの並行状況）のデザイン・レイアウトはそのまま維持し、そこに以下の要素を追加する形で更新してください。

### 追加する要素: 新しい指示を出す入力欄

自由記述のテキストボックスで、AIエージェントに新しい指示を出せるようにします。用途は2つあります。

1. **既存issueへの追加指示**
   - 判断待ち一覧・活動ログの各アイテムから「返信する」を選ぶと、そのissueに向けたテキスト入力ができる。
   - issueの状態を問わず送信可能（作業中のプロジェクトに割り込んで指示することも想定）。
   - 既存の「承認」「却下」ボタンは、この自由記述欄に定型文があらかじめ入った状態、という位置づけにする。つまり「承認」ボタン＝入力欄に「承認します。進めてください。」が自動入力された状態で送信、「却下」ボタン＝理由を書いて送信、という統一感のあるインタラクションにしてほしい（承認/却下ボタンと自由記述欄を別々のUIパーツとして独立させず、同じ入力欄を経由する体験にする）。

2. **新規タスクの作成**
   - 対象プロジェクトを選び、タイトルと指示内容（プロンプト）を入力して新しいタスクを作る。
   - 作成時に「今すぐ着手」「あとで着手（todo登録のみ）」を選べるトグル/ボタンを用意する。

### 配置・状態表示

- 常時画面下部固定、またはフローティングアクションボタンなど、**判断待ち一覧や活動ログを見ている最中でもすぐアクセスできる**位置に配置してほしい（就寝前に「あの件、明日はこう進めて」とさっと打ち込めるイメージ）。
- 「既存issueへの返信」と「新規タスク作成」はモード切り替え（タブ、セグメントコントロール等）で1つの入力UIにまとめてほしい。
- 実行中のプロジェクトへ指示を送った場合は、「現在実行中のため、完了後に指示が反映されます」のような、送信後の状態が伝わる表示（トースト通知やインラインメッセージ等）を含めてほしい。

### 更新後の成果物として欲しいもの

1. 既存のダッシュボードデザインに、上記の指示入力欄を統合した更新版（HTML/CSSのArtifact）
2. モバイル幅・PC幅それぞれでの見え方（特にモバイルでフローティング要素がどう振る舞うか）
3. 「既存issueへの返信」モードと「新規タスク作成」モードの切り替えインタラクション
4. 送信後の状態表示（実行中プロジェクトへの割り込み指示の場合を含む）
5. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色の一貫性を保ってください。不明点があれば、更新を進める前に質問してください。

## 補足（プロンプト利用者向けメモ）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない（最初のダッシュボードデザインが未作成の場合は、まず元のプロンプトを使うこと）。
- 対応する仕様変更は [requirements.md 2-3/2-7](./requirements.md#2-3-aiへの指示出し導線) 、[basic-design.md 2-3](./basic-design.md#2-3-指示出しapi内部api)（`instruct`アクション・新規issue作成API・ディスパッチキュー）を参照。
- デザイン更新後のArtifact URL/コードは、このリポジトリの実装issueに添付すること。
- 上記プロンプト本文中の「既存の4要素（判断待ち一覧／最近の活動ログ／利用量・リミットモニター／プロジェクトの並行状況）」は、このプロンプトを実際に使用した時点（指示入力欄追加時）のデザイン構成の記録であり、過去に送信した文面をそのまま残している。その後 [design-prompt-dashboard-diff-status-counts.md](./design-prompt-dashboard-diff-status-counts.md)（issue #115）で「最近の活動ログ」は廃止され、現在の要素は3つ（判断待ち一覧／利用量・リミットモニター／プロジェクトの並行状況（状態別件数表示・枠付きウィジェット化））になっている（issue #121）。本プロンプトを土台に新たな差分プロンプトを作成する場合は、この最新構成を前提にすること。
