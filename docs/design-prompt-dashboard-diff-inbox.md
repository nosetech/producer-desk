## ここからプロンプト

既存のproducer-deskダッシュボードの**プロジェクト別issue一覧画面**に、バグや機能アイデアを一行メモ感覚で記録できる「inbox」セクションを追加してください。既存の配色・コンポーネントのトーン・アイコンは維持してください。

### 背景

アイデアを思いついた時点では、タイトル・本文・受入条件を整えるほど考えがまとまっていません。「とりあえず忘れないよう記録だけしておく」ための置き場がinboxです。記録した項目は、既存の「AIに計画してもらう」フローで後から計画し、承認すると通常のissue（`status:todo`）に昇格します。inbox項目はAIには自動で実行されません。

### 追加する内容

1. **inboxセクション**: issue一覧画面の上部（または通常のissue一覧の上）に、通常のissueと明確に区別できるセクションを追加。見出し「inbox」と**件数バッジ**、開閉（折りたたみ）可能。
2. **登録フォーム**（セクション内、常時表示のコンパクトな1行形式）: 種別セレクト（バグ／機能アイデア／その他の3択、必須、既定は「機能アイデア」）＋「一言メモ」入力欄（必須）＋「追加」ボタン。「補足を書く」を開くと任意の本文テキストエリアが出る。
3. **項目一覧**（登録日時の新しい順）: 各行に種別バッジ（バグ／機能アイデア／その他で色分け）、タイトル、issue番号、登録日時、操作ボタン。
   - 「計画する」（主導線。既存の「AIに計画してもらう」を、その項目を入力元にして起動する）
   - 「編集」（種別・タイトル・本文をインライン編集）
   - 「削除」（確認ダイアログ付き。クローズ扱い）
4. **空状態**: 「inboxは空です。思いついたことを気軽にメモしてください」。
5. **状態**: 登録中・編集中・削除中の進行表示、エラー表示（既存のエラー表現に合わせる）。
6. **PC幅・モバイル幅**、**ライト・ダーク両方**。

### 成果物として欲しいもの

1. inboxセクション（項目あり、PC幅）
2. 空状態
3. 補足を開いた登録フォーム／インライン編集状態
4. 削除確認ダイアログ
5. モバイル幅とダークモードでの見た目
