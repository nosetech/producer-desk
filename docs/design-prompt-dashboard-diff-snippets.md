## ここからプロンプト

既存のproducer-deskダッシュボードのデザインに、**返信欄の定型文挿入**と**定型文管理画面**を追加してください。既存の画面（ダッシュボード／issue一覧／プロンプト設定ほか）のデザイン・配色・コンポーネントのトーンはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-323-snippets.dc.html`（と対の`feature/issue-323-snippets.logic.js`）という新規ファイルとしてデザインを作成してください。**

### 背景

既存issueへの返信（下部の入力欄＝ComposerBarの返信モード）では、「この方針で進めて」「まずテストを追加して」のような決まった指示を毎回手入力しています。よく使う文言を定型文として登録し、返信欄で選んでカーソル位置に挿入できるようにします。定型文は全プロジェクト共通で、プレースホルダは使わない固定文です。

### 1. 返信欄への「定型文」リストボックス

- 返信モードで、既存の「使用モデル」セレクト（ModelSelectRow）と同じ行、またはその直下に、同じ見た目のトーンで「定型文」セレクトを追加する。
- 初期表示は「定型文を選択…」。選択肢は登録済み定型文のタイトル。
- 選ぶと、テキストエリアのカーソル位置に本文が挿入され（範囲選択中は置換）、セレクトは「定型文を選択…」に戻る。
- 状態ごとの見え方:
  - 通常（数件登録済み）
  - 0件: セレクトを無効にし、横に「定型文を登録」リンク（管理画面へ）を控えめに表示
  - 取得失敗: セレクトを無効にし、「定型文を取得できませんでした」＋管理画面へのリンク。返信の送信自体は従来どおりできる
  - 送信中・返信先未選択: 他の入力と同様に無効

### 2. 定型文管理画面（`/snippets`）

- サイドバーに「定型文」ナビゲーション項目を追加する（既存の「プロンプト設定」と同列。モバイルのボトムナビにも相当する導線、キーボードショートカットのヒント表示があれば `s`）。
- 既存の**プロンプト設定画面と同じ一覧＋編集の2ペイン構成**にする。PC幅では左に定型文一覧、右に選択中の定型文の編集フォーム。モバイル幅では一覧→タップで編集画面に遷移。
- ページ上部の注記: 「登録した定型文は、返信欄の『定型文』から選んでカーソル位置に挿入できます。全プロジェクト共通です。」

#### 一覧

- 各行: タイトルと本文の先頭1行（省略表示）
- 並び替え: 各行に上へ／下へボタン（ドラッグハンドルを併用しても良い）。並び順が返信欄の選択肢の順になる
- 一覧上部に「＋ 新規追加」ボタン
- 0件時の空状態表示（「定型文はまだありません」＋新規追加ボタン）
- 件数表示（例: 「3 / 50件」。上限50件）

#### 編集フォーム

- タイトル（1行入力、最大50文字、文字数カウンタ付き）
- 本文（複数行テキストエリア、最大2000文字、文字数カウンタ付き）
- 検証: タイトル・本文が空、または上限超過のときはインラインエラーを表示し保存ボタンを無効化（既存のプロンプト設定のエラー表現に合わせる）
- ボタン: 「保存」（主ボタン）、「変更を破棄」、「削除」（危険系。押すと確認ダイアログ）
- 保存成功時は既存のトーストで「保存しました」
- 書き込みに失敗した場合（読み取り専用モード等）のエラー表示（既存のエラートースト／インラインエラーに合わせる）

### 成果物として欲しいもの

1. 返信欄の定型文セレクト（通常／0件／取得失敗の3状態）
2. PC幅の管理画面（一覧＋編集フォーム、編集中の状態）
3. モバイル幅での一覧画面と編集画面
4. 削除の確認ダイアログ
5. 検証エラー状態
6. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。
