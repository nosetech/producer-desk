## ここからプロンプト

既存のproducer-deskダッシュボードの「プロジェクトの並行状況」ウィジェットにある**プロジェクトチップのキューのミニ図**（issue #233で追加したもの）に、**AI計画ジョブ**（「AIに計画してもらう」で依頼した計画の生成処理）も表示できるようにしてください。他の要素のデザイン・レイアウトはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-335-queue-plan.dc.html`（と対の`feature/issue-335-queue-plan.logic.js`）という新規ファイルとして作成してください。** マスターの`.logic.js`は256KiBに近いため、`.logic.js`はマスターを読み込んで継承し、差分のスタイルだけを定義する形にしてください（`feature/issue-323-snippets.logic.js`と同じ方式）。

### 背景

AI計画ジョブは、自走タスク（issueへの指示）と同じプロジェクト単位のFIFOキューに積まれ、順番に処理されます。しかし現状のミニ図には計画ジョブが出ないため、計画ジョブの実行中は「実行中のタスクなし」（空き枠）に見え、後ろの自走タスクの「待機中 · N番目」も実際の順番とずれています。計画ジョブを、自走タスクと見分けられる1タスクとして、実際のキュー順のまま並べたいです。

### 変更内容

1. **計画ジョブのアイコン**
   - 実行中・待機中それぞれについて、自走タスクのアイコン（実行中=脈動するリング＋ドット、待機中=控えめな丸）と**一目で区別できる**計画ジョブ用のアイコンを提案してください。形の違い（例: ひし形・小さな「計画」グリフ等）で区別できること
   - 配色は、inbox一覧の計画状態バッジ（`PlanBadge`、計画中=青のトーン）を流用するかどうかも含めて決めてください
   - 実行中は自走タスクと同様に動きのある表現、待機中は静的。`prefers-reduced-motion`では形・色だけで区別できること
   - レーンの高さ・アイコンサイズ（20px枠）は既存と揃え、チップのレイアウトが崩れないこと
2. **並び順**: 計画ジョブも自走タスクと同じ列に実際のFIFO順で並べる。実行中の計画ジョブは先頭（空き枠ではなく実行中として）に置く。`+N`省略の対象にも含める
3. **ツールチップ（計画ジョブ用）**
   - 「AI計画」の種別表示（issue番号 `#n` の代わり。負の内部番号は表示しない）
   - `実行中` / `待機中 · N番目`
   - 依頼文の冒頭（1行目、44文字で省略）
   - プロジェクト名
   - inbox由来の計画なら、元のinbox番号（例: `inbox #123`）。新規タスク由来なら表示しない
   - 状態ラベルのバッジ（未着手等）は計画ジョブには無いので出さない
   - 依頼文が取得できない場合（実行中に計画が破棄された等）は「AI計画」＋位置表示のみのバリエーション
4. **ピン留め（タップ）時のリンク**: 計画ジョブにはGitHub issueのURLが無いため、GitHubへのリンクは出さないでください。リンクを出さない／計画確認画面（inboxの「計画を開く」パネル）へのリンクにする、のどちらが良いかも提案してください
5. **`+N`の省略表示とスクリーンリーダー向けの読み上げ**: 省略された中に計画ジョブがある場合は `#-1000` のような番号ではなく「AI計画」と表記する（例: `ほか 3件が待機中（#12, AI計画, #15）`）

### 成果物として欲しいもの

1. キューのミニ図の状態: 計画ジョブ実行中＋自走タスク待機／自走タスク実行中＋計画ジョブ待機（自走タスクと混在）／`+N`省略に計画ジョブを含む
2. 計画ジョブのツールチップ（実行中・待機中・inbox由来・依頼文なし）と、タップでピン留めした状態
3. PC幅・モバイル幅でのチップのレイアウト
4. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。不明点があれば、作成を進める前に質問してください。
