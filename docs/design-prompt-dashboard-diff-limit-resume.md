## ここからプロンプト

既存のproducer-deskダッシュボードの**判断待ち（needs-human-decision）カード**に、「利用リミット待ち」の状態表示と操作を追加してください。カード以外の要素のデザイン・レイアウトはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-331-limit-resume.dc.html`（と対の`feature/issue-331-limit-resume.logic.js`）という新規ファイルとして作成してください。** マスターの`.logic.js`は256KiBに近いため、`.logic.js`はマスターのロジック一式（ルートの拡張ファイル`ProducerDesk.review.logic.js`まで）を読み込んで継承し、差分のスタイルだけを定義する形にしてください（過去の`feature/issue-324-review-card.logic.js`と同じ方式。判断待ちカードのマークアップがダッシュボード側にあれば、機能用コピー`.dashboard.dc.html`を作ってください）。

### 背景

- Claude Code（サブスクリプション）の利用リミットに達すると、AIの作業が止まりissueが判断待ちになります。今は人間が解除時刻を覚えておいて、手動で再開指示を出しています。
- これを、次のどちらかを選べるようにします。
  1. **解除予定時刻に自動再開する（既定）**: 何もしなければ、オーケストレータが解除時刻を過ぎた後に同じセッションで自動再開する
  2. **別のAIモデルですぐ再開する**: 解除を待たず、LiteLLM Proxyのモデル（例: `qwen3-coder`、`gpt-oss-20b`）を選んで今すぐ再開する
- 自動再開を取り消して、判断待ちのまま手動で対応することもできるようにします。

### 変更内容

1. **利用リミット待ち表示**（自動再開が予定されているカードのみ）
   - 「利用リミット待ち」であることと、自動再開予定時刻（例: `11/28 13:00`）、残り時間（例: `あと2時間15分`）を表示する
   - 解除時刻を過ぎて再開待ちの間は「まもなく自動再開します」の表示にする
   - 従来の「AI」タグ付きの要約（失敗コメントの1行要約）の代わりに、この表示をカードの主な情報として置く
   - 待機中であることが伝わる配色・アイコン（時計など）にする。エラー（赤）には見せない
2. **「別モデルで今すぐ再開」操作**
   - ボタンを押すとダイアログを開き、LiteLLMのモデル（エイリアス名）を1つ選んで「このモデルで再開」で確定する
   - ダイアログに「選んだモデルは、このissueで以降も使われ続ける。元に戻すにはコメントで`/model claude_code`と指示する」旨を明記する
   - 投稿されるコメントの内容（`/model litellm:<エイリアス>`＋再開メッセージ）を、ダイアログ内でプレビュー表示してもよい
   - LiteLLMのモデルが1つも設定されていない場合は、ボタンを無効にし理由が分かるようにする
3. **「自動再開を取り消す」操作**
   - 確認ダイアログを出してから取り消す。取り消し後は通常の判断待ちカード（返信で手動対応）に戻る
4. 既存の「返信」「全文を表示」「レビュー待ちに変更」ボタン、ジョブ進捗表示、ディスパッチ診断、全文表示ダイアログは変更しない。新しい2つのボタンをどこに並べるか（返信との優先度）を決めてください。主ボタンは「返信」のままで構いません
5. 操作中（コメント投稿中）の進捗表示は既存のジョブ進捗表示（`JobStatus`）と同じ見た目にする
6. **配色**: 既存の配色（判断待ちのアクセント色、警告系の既存色、LiteLLM関連で使っている色）を使い、新しい色は増やさない

### 成果物として欲しいもの

1. 判断待ちカードの次の状態の見本
   - 利用リミット待ち（自動再開予定・残り時間あり）
   - 解除時刻を過ぎて自動再開待ち（まもなく再開）
   - LiteLLMモデル未設定（別モデルで再開ボタン無効）
   - 「別モデルで今すぐ再開」ダイアログ（モデル選択）
   - 「自動再開を取り消す」確認ダイアログ
   - 操作の実行中（進捗表示あり）
2. PC幅・モバイル幅（〜640px、タップ領域36px以上）での見え方
3. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。不明点があれば、作成を進める前に質問してください。
