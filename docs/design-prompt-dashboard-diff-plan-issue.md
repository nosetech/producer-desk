## ここからプロンプト

既存のproducer-deskダッシュボードの**新規タスク作成UI（コンポーザー）**に、「やりたいことだけ書くとAIが計画（issueのタイトル・本文）を作成し、確認・修正・承認してからissueとして登録する」モードを追加してください。既存の配色・コンポーネントのトーン・アイコンは維持してください。

### 背景

現在の新規タスク作成は、プロジェクトを選び、タイトルと本文を自分で書いて登録する方式のみです。そこに「AIに計画してもらう」モードを追加します。**承認するまでissueは作成されません。**

### 追加・変更する内容

1. **作成モードの切替**: 新規作成コンポーザーの上部に、セグメント切替「自分で書く」（従来どおり）／「AIに計画してもらう」を追加。
2. **AIモードの入力ステップ**: 「やりたいこと」を書く自由記述欄と「計画を作成」ボタン（プロジェクト選択・モデル選択は既存どおり）。
3. **計画生成中の状態**: 既存の進捗表示（段階ステッパー）に合わせ、「待機中（キュー◯番目）」と「計画を作成中」を区別して表示。二重送信防止のため入力欄・ボタンは無効化。
4. **計画確認ステップ**:
   - 「タイトル」入力欄と「本文」複数行テキストエリア（編集可能。本文は等幅でもMarkdownプレビューでもよいが編集可能であること）。
   - 「AIに修正を指示」入力欄＋送信ボタン（送信すると計画を再生成する。何度でも繰り返せる。修正中は生成中状態を表示し、直前の計画は残す）。
   - 「承認して登録」（主ボタン）、「やり直す」（「やりたいこと」入力に戻る）、「キャンセル」。
   - 登録時の配信方法（即時ディスパッチ／キュー登録）の選択は既存コンポーザーのUIをそのまま踏襲。
   - 「承認するまでissueは作成されません」の注記を控えめに表示。
5. **エラー状態**: 計画の出力を解釈できなかった／タイムアウト／利用リミット到達を、既存のエラー表現（トースト／インラインエラー）で示し、「再試行」導線を付ける。
6. **PC幅・モバイル幅**、**ライト・ダーク両方**。

### 成果物として欲しいもの

1. 入力ステップ（モード切替付き、AIモード選択状態）
2. 計画生成中（待機中／作成中）
3. 計画確認ステップ（編集可能なタイトル・本文、AI修正指示欄、承認ボタン）
4. エラー状態
5. モバイル幅とダークモードでの見た目
