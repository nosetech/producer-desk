# Claude Designへの追加指示プロンプト: サイドバーとプロジェクトissue一覧ページの追加（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #116）。既に作成済みのデザインがある場合は、それを土台に更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaudeとのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインに、**サイドバー**と**プロジェクトのissue一覧を表示する専用ページ**を追加してください。既存のダッシュボード画面（判断待ち一覧／利用量・リミットモニター／プロジェクトの並行状況／新しい指示を出す入力欄）のデザイン・レイアウト・配色はそのまま維持し、画面の外枠にサイドバーを加え、新しい画面を1つ追加する形で更新してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html`）は上書きせず、`feature/issue-116-project-issues-page.dc.html` という新規ファイルとしてデザインを作成してください。**

### 変更1: サイドバーの追加

- 画面左にサイドバーを設け、**「ダッシュボード」画面**と**「issue一覧」画面**を切り替えられるようにしてください
- ナビゲーション項目は「ダッシュボード」「issue一覧」の2つ。現在表示中の項目が分かる選択状態の表現を入れてください
- PC幅では常時表示（折りたたみ可能でも可）、モバイル幅ではハンバーガーボタン等で開閉するドロワー形式、またはボトムナビゲーション等、モバイルに適した形を提案してください
- 既存ヘッダー（テーマ切替等）との役割分担・配置の整理もお任せします
- 既存の「新しい指示を出す入力欄」（画面下部固定）が、サイドバー追加後もレイアウト崩れなく動作するようにしてください

### 変更2: プロジェクトのissue一覧ページの追加

サイドバーの「issue一覧」から開く、プロジェクト単位のissue一覧画面です。

- 画面上部で**プロジェクトを選択**できる（セレクトボックス、タブ、チップ列など。プロジェクトは並行3〜5件を想定）。ダッシュボードの「プロジェクトの並行状況」ウィジェットのプロジェクトチップをクリックしたときも、このページの該当プロジェクトが選択された状態で開く想定です
- 選択中プロジェクトのissueを一覧表示する。各行には以下を表示してください
  - issue番号とタイトル
  - 状態バッジ（未着手／作業中／判断待ち／レビュー待ち／完了。いずれの状態ラベルも付いていないissueは「タグなし」。配色は既存の状態バッジと揃える）
  - 最終更新日時（相対表記）、コメント数
  - **孤立した「作業中」issue**（作業中のはずなのに実際には処理が止まっているもの）の警告表示。ダッシュボード側のチップに入れた警告アイコンと一貫した表現にし、一覧の中でも一目で分かるようにしてください
- **状態での絞り込み**（フィルタ）と、並び順（更新日時順が基本）を用意してください。完了issueは既定で非表示、または目立たない扱いにする案も歓迎します
- 各issue行から、既存の「新しい指示を出す入力欄」の**返信モード**に繋がる導線（「返信する」ボタン等）を用意してください。状態を問わず（未着手・作業中のissueにも）指示を送れることが目的です
- issueが0件の場合・読み込み中・取得失敗の各状態のデザインも含めてください
- 件数が多い場合（最大100件程度）でも見やすいレイアウトにしてください。モバイル幅では表形式ではなくカード形式にするなど、適した形を提案してください

### 更新後の成果物として欲しいもの

1. サイドバーを加えたダッシュボード画面（PC幅・モバイル幅）
2. issue一覧ページ（PC幅・モバイル幅）。プロジェクト選択・状態フィルタ・孤立作業中の警告表示・0件/読み込み中/エラー状態を含む
3. サイドバーによる画面切替、およびダッシュボードのプロジェクトチップからissue一覧への遷移のインタラクション
4. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色の一貫性を保ってください。不明点があれば、更新を進める前に質問してください。
