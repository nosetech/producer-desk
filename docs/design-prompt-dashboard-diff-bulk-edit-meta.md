# Claudeチャットへの追加指示プロンプト: issue一覧のマイルストーン・ラベル一括変更／個別編集（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #305）。[マイルストーン・タグ表示とフィルタ（issue #303）](./design-prompt-dashboard-diff-milestone-tags.md)の内容を引き継いだ差分です。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaudeとのやり取りに貼り付けてください。

## ここからプロンプト

既存のproducer-deskダッシュボードの**プロジェクト別issue一覧画面**に、issueのマイルストーンとラベル（タグ）を一覧上で変更する機能を追加してください。既存の配色・トーン・アイコンは維持してください。`feature/issue-303-milestone-tags.dc.html`（マイルストーン・タグ表示とフィルタ）の内容を引き継いだ差分にしてください。

### 追加する内容

1. **行頭のチェックボックス**: 各issue行（PC幅）とカード（モバイル幅）の先頭にチェックボックス。テーブルヘッダーに「すべて選択」チェックボックス（現在のフィルタ後の表示行が対象、一部選択時は中間状態）。選択行は背景色で分かるようにする。
2. **一括操作バー**: 1件以上選択すると一覧上部（スクロールしても見える位置）に表示。「N件選択中」、マイルストーン選択（変更しない／設定する＋既存マイルストーンから選択／解除する）、ラベル追加の複数選択、ラベル削除の複数選択、「適用」ボタン、「選択解除」ボタン。同じラベルを追加と削除の両方に指定できない（片方で選ぶともう片方で無効化）。適用中は既存のSendingSpinnerで送信中表示し二重押下を防ぐ。
3. **個別編集ポップオーバー**: 行（カード）のマイルストーン・タグ表示（無い場合は「＋」追加ボタン）をクリックして開く。マイルストーン（単一選択・解除可）とラベル（複数選択チェックリスト）を選んで「適用」。一括操作バーと同じ部品を再利用した見た目にする。
4. **選択肢**: 既存のオープン中マイルストーンと既存ラベルのみ。状態ラベル（`status:*`・`needs-human-decision`）は選択肢に出さない。新規作成・削除・名称変更の入力欄は作らず、選択肢の末尾に「新しく作るにはGitHubで作成してください」の案内を小さく表示。マイルストーン／ラベル一覧が取得できない場合は変更UIを無効表示にしツールチップで理由を示す。
5. **結果表示**: 全件成功時はトースト「N件を更新しました」で選択解除。一部失敗時は「N件成功・M件失敗」の警告トーストで、失敗分だけ選択状態を残し失敗行に小さなエラー印。読み取り専用モードで拒否された場合は既存のエラートーストと同じ見た目でエラー表示。
6. **状態**: 未選択／一部選択／全選択／適用中／部分失敗／読み取り専用エラー／選択肢なし（無効）。
7. **PC幅・モバイル幅**、**ライト・ダーク両方**。モバイルでは一括操作バーを画面下部固定のシートにしてもよい。

### 成果物として欲しいもの

1. チェックボックス付きissue一覧（PC幅・未選択と一部選択）
2. 一括操作バー（各入力が開いた状態を含む）
3. 個別編集ポップオーバー
4. 適用中・部分失敗・読み取り専用エラー・選択肢なしの各状態
5. モバイル幅とダークモードでの見た目

**既存のマスターファイル（`ProducerDesk.dc.html`）は直接上書きせず、`feature/issue-305-bulk-edit-meta.dc.html` という新規ファイルとして作成してください。** ファイルが大きくなる場合は、取得時に途中で欠けないよう（256KiB程度が目安）分割してください。不明点があれば、作成を進める前に質問してください。
