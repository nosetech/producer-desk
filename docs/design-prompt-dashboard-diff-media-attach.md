# Claudeチャットへの追加指示プロンプト: 返信欄・新規タスク作成での画像・動画の添付（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #301）。[利用リミット待ちの判断待ちカード（issue #331）](./design-prompt-dashboard-diff-limit-resume.md)までの内容を引き継いだ差分です。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaudeとのやり取りに貼り付けてください。

---

## ここからプロンプト

既存のproducer-deskダッシュボードの**コンポーザー（返信欄「既存issueへ返信」と新規タスク作成フォーム「新規タスク作成」の手動入力モード）**に、画像・動画を添付する機能を追加してください。コンポーザー以外の要素のデザイン・レイアウトはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-301-media-attach.dc.html`（と対の`feature/issue-301-media-attach.logic.js`）という新規ファイルとして作成してください。** マスターの`.logic.js`は256KiBに近いため、`.logic.js`はマスターのロジック一式（ルートの拡張ファイル`ProducerDesk.limit.logic.js`まで）を読み込んで継承し、差分のスタイルだけを定義する形にしてください（過去の`feature/issue-331-limit-resume.logic.js`と同じ方式）。

### 背景

- 今はAIへの指示（issueコメント）も新規タスク（issue本文）もテキストしか送れません。表示崩れの指摘、デザインの参考画像、操作の様子を録った動画など、画像や動画を見せた方が早い指示も文章で説明するしかありません。
- GitHubのコメント添付（`user-attachments`）として送るため、添付できるのは**画像（png/jpg/jpeg/gif）と動画（mp4/mov/webm）のみ**です（svg・pdf・txt・zip等は不可）。
- 上限: **1ファイル10MB・1回10ファイル・合計50MB**

### 変更内容

1. **添付ボタン**
   - 返信欄のテキストエリア（「追加の指示を入力…」）と、新規作成（手動入力）の「指示内容 / プロンプト」テキストエリアの近くに、「画像・動画を添付」ボタン（クリップ等のアイコン）を置く
   - 複数選択可。ボタン付近に、対応形式と上限が分かる控えめな補足（例: `png/jpg/gif・mp4/mov/webm、1件10MBまで・最大10件`）を出す
2. **選択済みの一覧（添付トレイ）**
   - 画像はサムネイル、動画は動画アイコン＋ファイル名・サイズを並べる
   - 1件ずつ「×」で外せるようにする
   - 件数と合計サイズ（例: `3件・12.4MB / 50MB`）を表示する
3. **ドラッグ&ドロップ／貼り付け**
   - テキストエリアへファイルをドラッグしている間、ドロップを受け付けている状態をはっきり示す（破線枠＋「ここにドロップして添付」等）
   - クリップボードからの画像貼り付け（スクリーンショット）にも対応することを、プレースホルダーや補足でさりげなく伝える
4. **エラー表示**
   - 対応外の形式、1ファイルのサイズ超過、件数超過、合計サイズ超過で弾いたときに、どのファイルがなぜ弾かれたかを表示する（例: `report.pdf: 対応していない形式です`）
   - エラーは赤系の既存のエラー色で。弾かれたファイルはトレイには入れない
5. **送信**
   - 返信欄は、添付が1件以上あれば本文が空でも「指示を送信」を押せる
   - 送信中の進捗は既存のジョブ進捗表示（`JobStatus`）と同じ見た目のままでよい（段階の文言に「添付をアップロード」が加わる程度）
   - 送信中はトレイの操作（追加・削除）を無効にする
6. 既存の「使用するモデル」「定型文」セレクト、返信先コメントの引用表示、計画モードは変更しない。添付は手動入力モードのみ（計画モードには付けない）
7. **配色**: 既存の配色（アクセント色・エラー色・境界線色）を使い、新しい色は増やさない

### 成果物として欲しいもの

1. 次の状態の見本
   - 返信欄: 添付なし（ボタンのみ）／画像2件＋動画1件を添付済み
   - 新規作成（手動入力）: 画像を添付済み
   - テキストエリアへドラッグ中（ドロップ受付表示）
   - 形式・サイズ・件数エラーの表示
   - 送信中（トレイ操作が無効）
2. PC幅・モバイル幅（〜640px、タップ領域36px以上）での見え方
3. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。不明点があれば、作成を進める前に質問してください。
