# Claudeチャットへの追加指示プロンプト: issue一覧のキーボードショートカット（カーソル行・ショートカットガイド）（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #322）。[issue一覧のマイルストーン・ラベル一括変更（issue #305）](./design-prompt-dashboard-diff-bulk-edit-meta.md)の行頭チェックボックス・選択行の見た目を引き継いだ差分です。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaudeとのやり取りに貼り付けてください。

## ここからプロンプト

既存のproducer-deskダッシュボードの**プロジェクト別issue一覧画面**を、キーボードだけで操作できるようにします。そのための見た目として、**キーボード操作用の「カーソル行」の強調表示**と、**画面下部のショートカットガイド**を追加してください。それ以外の要素のデザイン・レイアウトはそのまま維持してください。

**重要: 既存のマスターファイル（`ProducerDesk.dc.html` / `ProducerDesk.logic.js`）は直接上書きせず、`feature/issue-322-keyboard-shortcuts.dc.html`（と対の`feature/issue-322-keyboard-shortcuts.logic.js`）という新規ファイルとして作成してください。** マスターの`.logic.js`は256KiBに近いため、`.logic.js`はマスターを読み込んで継承し、差分のスタイルだけを定義する形にしてください（`feature/issue-325-decision-card.logic.js`と同じ方式）。

### 割り当てるショートカット

| 対象 | キー | 動作 |
|---|---|---|
| プロジェクト（上部のタブ） | `h` / `l` | 左／右のプロジェクトへ切り替える |
| issue一覧 | `j` / `k` | カーソルを1つ下／上のissueへ移す |
| issue一覧 | `x` | カーソル行の行頭チェックボックスの選択を切り替える |
| issue一覧 | `Esc` | issueの選択をすべて解除する |
| 状態フィルタ（すべて・未着手・作業中…） | `Shift`+`h` / `Shift`+`l` | 左／右のフィルタを選ぶ |

既存の画面遷移ショートカット（`d` ダッシュボード / `i` issue一覧 / `p` プロンプト設定 / `s` 定型文）はサイドバーのナビ項目に`kbd`で表示済みです。

### 追加する内容

1. **カーソル行の強調表示**
   - `j` / `k` で動かすカーソル（フォーカス行）は、チェックボックスの選択（`rowSelected` / `cardSelected`: 青系の背景＋左端の青いインセット線）とは**別のもの**です。両者が見た目で区別できるようにしてください（例: カーソル行は枠線のみ・選択行は背景色、など）
   - 「カーソル行かつ選択行」の重なった状態、「カーソル行かつ停止の可能性（`rowOrphan`、警告色の背景）」の状態でも、両方の意味が読み取れるようにしてください
   - PC用の行（`row`）とモバイル用のカード（`card`）の両方に定義してください
2. **画面下部のショートカットガイド**
   - 上の表の内容を、サイドバーの`navKbd`と同じトーンの`kbd`表示で並べる（例: `j` `k` 移動 · `x` 選択 · `Esc` 選択解除 · `h` `l` プロジェクト · `⇧H` `⇧L` フィルタ）
   - 配置（issue一覧パネルの下か、画面下端に固定か）と配色を決めてください。一覧のフッター（「N 件を表示」）や一括変更バーと重ならず、一覧の閲覧を邪魔しない控えめな表示にしてください
   - `Shift`付きのキーの表記（`⇧H` / `Shift+H` 等）を決めてください
3. **モバイル幅（〜640px、ボトムナビ表示幅）ではショートカットガイドを表示しない**
4. **配色**: 既存の配色トークンを使い、新しい色は増やさない

### 成果物として欲しいもの

1. PC幅のissue一覧で、次の状態の見本
   - カーソル行のみ
   - カーソル行と選択行が別の行
   - カーソル行が選択行と重なっている
   - カーソル行が停止の可能性の行と重なっている
2. 画面下部のショートカットガイド（一括変更バー表示中の状態も含む）
3. モバイル幅（ガイド非表示、カードのカーソル表示）
4. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色・アイコンの一貫性を保ってください。スタイル値は`.logic.js`側のスタイルオブジェクトとして定義してください。不明点があれば、作成を進める前に質問してください。

## 補足（プロンプト利用者向けメモ）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない。
