## ここからプロンプト

既存のproducer-deskダッシュボードの**プロジェクト別issue一覧画面**に、マイルストーンと状態以外のタグ（`bug`・`enhancement`など）の表示、およびそれらによるフィルタ（OR/AND切替付き）を追加してください。既存の配色・コンポーネントのトーン・アイコンは維持してください。

### 追加する内容

1. **行・カードの表示**: 各issue行（PC幅）とカード（モバイル幅）に、マイルストーン（1つ、無い場合は非表示）と、状態以外のタグのチップ（0個以上）を表示。PC幅ではタイトルセルの2行目に置き、列レイアウトは崩さない。タグが多い場合は折り返すか`+N`で省略。状態ラベルはタグとして重複表示しない。
2. **フィルタ行**: ツールバーの既存の状態フィルタとは別に、「マイルストーン」「タグ」のフィルタ行を追加。複数選択できるチップで、各チップに件数を表示し、選択解除できる。マイルストーン／タグが1つも存在しないリポジトリでは行ごと非表示。
3. **OR/ANDトグル**: セグメントボタン（「OR」「AND」）で、複数選択時の結合方法を切り替える。選択が合計2つ未満のときは無効表示。現在のモードが分かること。ANDでマイルストーンを複数選ぶと必ず0件になるため、その旨が画面上で分かる表現（注記やマイルストーンの選択を1つに制限など）を入れる。
4. **0件状態**: 「この条件に一致するissueはありません」と「絞り込みを解除」ボタン。新しいフィルタも解除対象にする。
5. **PC幅・モバイル幅**、**ライト・ダーク両方**。

### 成果物として欲しいもの

1. マイルストーン・タグ表示付きのissue一覧（PC幅）
2. フィルタ行とOR/ANDトグル（OR・AND・無効の各状態）
3. 0件状態
4. モバイル幅とダークモードでの見た目
