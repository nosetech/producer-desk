# Claude Designへの追加指示プロンプト: レビュー承認時のマージ対象PR選択UI（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #206）。既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けて使います。単独では使わない。

---

## ここからプロンプト

レビュー待ちカードの「承認」時に、マージするPRを選ぶUIを追加してください。背景: issueに対応PRの候補が複数ある（または特定できない）場合、オーケストレータは自動マージせず、ユーザーにどのPRをマージするか選ばせます。

【要件】

1. 候補が複数のレビュー待ちカードでは、タイトル横のPR #Nリンクの代わりに「PR候補 N件」のような表示にして、どのPRがマージされるか誤解されないようにする。候補が0件の場合は「PR未特定」（リンクなし）を表示する。
2. 承認ボタン押下時、候補が1件なら従来の確認ダイアログのまま。複数の場合は、既存の確認ダイアログと同じトーンで「マージするPRを選択」ダイアログを開く。候補PRを縦に並べ、それぞれにラジオ選択、PRタイトル、#番号、headブランチ→baseブランチ、Draftバッジ（該当時）、GitHubで開く外部リンクを表示する。未選択の間は「マージして承認」ボタンを無効にし、選択後に有効化する。
3. 候補が0件で特定できない場合の空状態（「対応PRが見つかりません。GitHub上でPRを確認してください」程度）も用意する。
4. Draft PRを選択したときは選択不可にせず、警告バナー（既存のwarningBannerと同じトーン）で「このPRはDraftです。Draft PRはマージできないため、承認が失敗する可能性があります。Ready for reviewにしてから承認することを推奨します。」と伝える（「マージして承認」は押せるまま）。
5. 選択状態・hover・ライト/ダーク両モード・モバイル幅でも崩れないこと。既存デザインのトーン・配色・角丸・余白と一貫させる。
