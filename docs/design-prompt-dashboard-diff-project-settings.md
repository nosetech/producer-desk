# Claude Designへの追加指示プロンプト: プロジェクト設定画面（実行手段・モデル選択）の追加（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です。既に作成済みのモックアップ（Artifact）がある場合は、それを更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインに、**プロジェクトごとの実行手段・モデルを設定するダイアログ**を追加してください。既存要素（判断待ち一覧／利用量・リミットモニター／プロジェクトの並行状況／新しい指示を出す入力欄）のデザイン・レイアウトはそのまま維持し、そこに以下の要素を追加する形で更新してください。

### 背景

このダッシュボードでは、AIエージェントに自走タスクを実行させる際の実行手段を、プロジェクト（リポジトリ）ごとに選べるようにします。

- (A) Claude Code CLIを直接使う（サブスクリプション契約の範囲内、追加コストなし）
- (B) 他のAIモデル・ローカルLLMを、モデル中継サーバー（LiteLLM Proxy）経由で使う（従量課金）

この選択をプロジェクトごとの「デフォルト設定」として保存できる画面が必要です。

### 追加する要素: プロジェクトの実行設定ダイアログ

1. **開き方**: 「プロジェクトの並行状況」ウィジェットの各プロジェクトチップに、設定用のアイコンボタン（歯車アイコン等）を追加してください。既存の「＋（新規タスク作成）」ボタンと並べて配置し、押すとそのプロジェクト専用の設定ダイアログが開きます。
2. **ダイアログの内容**:
   - 対象プロジェクト名（読み取り専用の見出し）
   - 実行手段の選択（2択、セグメントコントロールまたはラジオボタン等）
     - 「Claude Code（サブスクリプション）」
     - 「LiteLLM Proxy経由（従量課金）」
   - 後者を選んだ場合のみ表示される、使用するモデルの選択欄（プルダウン。選択肢の例: `project-a-openai-gpt4o`、`project-b-ollama-qwen`のような名前が並ぶイメージで構いません）
   - 「保存」「キャンセル」ボタン
   - 保存中・保存成功・保存失敗それぞれの状態が伝わる表示（既存のトースト通知や、既存の承認確認ダイアログで使っているローディング表現との一貫性を持たせてください）
3. **見た目の一貫性**: 既存の「承認」操作で使っている確認ダイアログ（半透明の背景オーバーレイの上に浮かぶ角丸パネル）と同じトーン・構造を踏襲してください。新しい配色やパネル形状を新規に考案する必要はありません。

### 更新後の成果物として欲しいもの

1. 既存のダッシュボードデザインに、上記の設定ダイアログを統合した更新版（HTML/CSSのArtifact）
2. プロジェクトチップに追加した設定ボタンの見た目（ホバー状態を含む）
3. ダイアログを開いた状態、実行手段ごとの表示切り替え（LiteLLM Proxy選択時にモデル選択欄が現れる様子）
4. 保存中・保存成功・保存失敗それぞれの状態表示
5. モバイル幅・PC幅それぞれでの見え方
6. ライトモード・ダークモード両方での見た目

既存デザインとのトーン・配色の一貫性を保ってください。不明点があれば、更新を進める前に質問してください。

## 補足（プロンプト利用者向けメモ）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない（最初のダッシュボードデザインが未作成の場合は、まず元のプロンプトを使うこと）。
- 対応する仕様変更は [issue #148](https://github.com/nosetech/producer-desk/issues/148)・[issue #175](https://github.com/nosetech/producer-desk/issues/175)、[basic-design.md 4章「実行手段の選択」](./basic-design.md#実行手段の選択自走タスク本体issue-174)（永続化API `PATCH /api/projects/{repo}/settings` の仕様）を参照。
- デザイン更新後のArtifact URL/コードは、issue #175に記録し、`CLAUDE.md`「画面デザインの実装ルール」のURLも必要に応じて更新すること。
