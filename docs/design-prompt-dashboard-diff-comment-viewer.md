# Claude Designへの追加指示プロンプト: コメント全文表示と返信UI内コメント表示（差分）

[design-prompt-dashboard.md](./design-prompt-dashboard.md)でお願いしたダッシュボードデザインに対する**追加の変更依頼**です（issue #193。[design-prompt-dashboard-diff.md](./design-prompt-dashboard-diff.md)の指示入力欄追加の後に依頼する想定）。既に作成済みのモックアップ（Artifact）がある場合は、それを更新する形で対応してください。ゼロから作り直す必要はありません。以下を丸ごとコピーし、既存デザインを作成したClaude（Artifact）とのやり取りに貼り付けてください。

---

## ここからプロンプト

前回お願いしたproducer-deskダッシュボードのデザインに、**AIコメントの全文を読みやすく確認できるUI**と、**返信入力欄の中に返信先コメントを表示するUI**を追加してください。既存のレイアウト・配色・コンポーネント構成はそのまま維持し、以下の要素だけを追加・変更してください。

### 背景

「判断待ち」「レビュー待ち」の各カードは、最新のAIコメントを3行までの要約で表示し、全文はブラウザ標準のツールチップ（`title`属性）でしか読めません。長文・改行を含むコメントが読みにくく、タッチ端末では表示すらできません。また「返信」を押して入力欄を開くと、返信先のコメントが見えず、コメントを見ながら返信を書けません。

### 変更1: カードでのコメント全文表示

- 判断待ちカード・レビュー待ちカードの要約行に、全文を開く操作（「全文を表示」ボタン等）を追加する。ツールチップによる全文表示は廃止する。
- 全文の表示形態は、カード内の展開表示（アコーディオン）か、モーダルダイアログのどちらかで、既存デザインに最もなじむ方を選ぶ（推奨: 全文を読む操作はモーダル）。モーダルの場合は、既存の承認確認ダイアログと同じ背景・角丸・影・アニメーションの言語に揃える。
- 全文は改行・段落をそのまま保持して表示する（等幅ではなく通常の本文フォント。コードブロックや箇条書きが崩れないこと）。
- 長文は最大高さを設けて内部スクロールできるようにする。
- 投稿者・投稿時刻・GitHubコメントへのリンク（外部リンクアイコン付き）を併せて表示する。
- Esc／背景クリックで閉じられること、閉じるボタンがあることが分かるデザインにする。

### 変更2: 返信UI内への返信先コメント表示

- 「返信」を押して入力欄（指示入力欄の返信モード）が開いたとき、入力欄の上に、返信先のAIコメント全文を**読み取り専用**で表示する。
- コメント表示部は最大高さ＋内部スクロールとし、**コメントと入力欄を同時に視認できる**レイアウトにする。
- 返信先コメントは「返信を開いた時点のもの」を表示し続ける（返信中にコメントが更新されても入れ替わらない）。コメント表示部に投稿時刻を添えて、どの時点のコメントかが分かるようにする。
- コメント表示部を折りたたむ操作を用意してもよい（入力欄を広く使いたい場合のため）。

### 共通の要件

- モバイル幅でも、コメント表示と入力欄が両立するレイアウトにする（フローティングの入力欄がコメントで画面を覆い尽くさないこと）。
- ダーク／ライト両テーマで配色を用意する。

### 更新後の成果物として欲しいもの

1. 既存のダッシュボードデザインに、上記2つの要素を統合した更新版（HTML/CSSのArtifact）
2. モバイル幅・PC幅それぞれでの見え方
3. 全文表示（開いた状態）と、返信入力欄にコメントが表示された状態の両方を確認できる見本

## 補足（プロンプトの外）

- この差分プロンプトは [design-prompt-dashboard.md](./design-prompt-dashboard.md) に対する追加変更であり、単独では使わない。
- Claude Design側でデザインが更新されたら、実装時に`DesignSync`で実ソース（`ProducerDesk.dc.html`）を取得し、コメント表示部のスタイル値を読み取ってから実装すること（[CLAUDE.md](../CLAUDE.md)の「画面デザインの実装ルール」参照）。
